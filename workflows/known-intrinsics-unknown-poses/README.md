# Calibrated-intrinsics reconstruction (unknown camera positions)

This experiment keeps the Olympus's **calibrated intrinsics fixed** while PyCOLMAP estimates camera positions from overlapping photos. It is a comparison against the existing uncalibrated baseline, **not a guarantee** against the previous `no initial pair` failure.

## Prerequisites

Use the Python virtual environment where `python -c "import pycolmap; print(pycolmap.__version__)"` succeeds. We target PyCOLMAP 4.2.1. The script additionally uses Pillow to check the input image dimensions.

The calibration file is generated by `scripts/calibrate_camera.py` and normally lives at `calibration/olympus_intrinsics.json`. It must correspond to the **same lens, zoom/focal length, focus setting and image resolution** as the reconstruction photos. The calibration JSON records the five OpenCV distortion terms; we use `fx,fy,cx,cy,k1,k2,p1,p2` for COLMAP's OPENCV camera model. OpenCV's optional `k3` coefficient is **not** represented in that model; this approximation is acceptable only when `k3` is small. If calibration has material high-order distortion, use a suitable model or undistort first.

## Run the test

Open PowerShell in the repository root, activate `.venv`, and run:

```powershell
python run.py --images data/test01/images --output output/calibrated01 --calibration calibration/olympus_intrinsics.json --colmap-only
```

Use a **fresh output folder**, because COLMAP refuses to overwrite an existing feature database.

For an A/B test, use the *same input images* in a separate output folder without calibration:

```powershell
python run.py --images data/test01/images --output output/uncalibrated02 --colmap-only
```

Compare whether either run registers images, and how many. When calibrated mode runs, it prints the supplied OPENCV camera parameters; bundle adjustment's intrinsic refinement is disabled. Camera poses and point locations are still solved normally.

If no model is generated, inspect image overlap, SIFT feature matching and initial-pair geometry; calibration cannot compensate for absent image correspondences or inadequate parallax.

**Note:** A calibrated reconstruction can be passed to gsplat using the existing `--skip-colmap` training path, provided the separate pinned trainer setup is working. This PR changes only reconstruction, not gsplat.

## Calibration JSON compatibility

Required keys: `camera_matrix`, `distortion_coefficients`, `image_width`, `image_height`. The CLI validates the dimensions against the first source photo. It assumes all photos are the same resolution and lens configuration.
